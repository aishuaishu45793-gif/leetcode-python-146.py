## 🚀 How to Run the Programs

### Step 1: Install Python

Download and install Python if it is not already installed on your computer.

### Step 2: Install Visual Studio Code

Install Visual Studio Code to write and run Python programs.

### Step 3: Clone the Repository

Open your terminal and run the following command, replacing `<repository-url>` with the URL of the repository containing the program you want to download.

```bash
git clone <repository-url>
```

Alternatively, download the Python file directly from its individual GitHub repository.

### Step 4: Open the Project

Open the downloaded folder in Visual Studio Code.

### Step 5: Run a Python Program

Open the terminal in VS Code and execute the program you want to run.

For example:

```bash
python 146.py
```

Replace `146.py` with the appropriate filename when running another program.
